# 🎓 WhatsApp Group Material Extractor

A Streamlit web app that extracts teacher messages (Syllabus, Notes, PDFs) from exported WhatsApp group chats.

---

## 🚀 Features

- 📂 Upload WhatsApp chat (.txt file)
- 👨‍🏫 Select one or multiple teachers
- 📊 View message summary
- 📥 Download filtered data as:
  - CSV file
  - Excel (.xlsx) file

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- XlsxWriter
- Regular Expressions (Regex)
